# Переключатель профилей displayctl для IINA

[English version](README.md)

Компактный Lua-скрипт для [IINA](https://iina.io/) и mpv на macOS. Он определяет цветовые метаданные воспроизводимого видео, находит подходящий референсный режим Apple в выводе `displayctl profiles`, переключает монитор по актуальному номеру профиля и восстанавливает системные настройки после завершения воспроизведения.

> **О проекте:** Скрипт создан OpenAI Codex по инструкциям автора проекта и протестирован на реальном оборудовании.

В работе скрипта используется утилита управления монитором [VitaliyYakob/displayctl](https://github.com/VitaliyYakob/displayctl), ранее опубликованная автором проекта.

## Возможности

- Получает `primaries`, `gamma` и `colormatrix` из свойства mpv `video-params`.
- Сопоставляет метаданные видео с точными названиями профилей из `displayctl`.
- Определяет номера профилей динамически, без жёстко заданных номеров.
- Кэширует разобранный список профилей на время работы экземпляра плеера IINA.
- Устанавливает выбранный индекс частоты обновления во время воспроизведения.
- Восстанавливает `--profile default --rate default` после stop, окончания или выгрузки файла, а также штатного завершения IINA.
- Показывает в OSD IINA метаданные видео, название профиля и найденный номер.

## Требования

- macOS
- IINA с включённой поддержкой Lua-скриптов mpv
- [VitaliyYakob/displayctl](https://github.com/VitaliyYakob/displayctl), установленный по пути `/usr/local/bin/displayctl`
- Монитор, референсные режимы которого доступны через `displayctl profiles`

## Установка

1. Откройте в IINA **Настройки → Дополнительно**.
2. Включите **Use config directory** и укажите `~/.config/mpv`.
3. Если каталога для скриптов нет, создайте его:

   ```sh
   mkdir -p ~/.config/mpv/scripts
   ```

4. Скопируйте `iina-display-profile.lua` в:

   ```text
   ~/.config/mpv/scripts/iina-display-profile.lua
   ```

5. Полностью завершите IINA и запустите приложение снова.

## Принцип работы

При загрузке первого файла скрипт выполняет:

```sh
/usr/local/bin/displayctl profiles
```

Вложенные строки профилей индексируются по точному названию. Например:

```text
[1] Studio Display XDR (Основной):
    [3] HDR Video (P3-ST 2084)
    [4] HDTV Video (BT.709-BT.1886) *
```

Для видео с BT.709 и функцией передачи BT.1886 выбирается название `HDTV Video (BT.709-BT.1886)`. Скрипт находит для него номер `4` и выполняет:

```sh
/usr/local/bin/displayctl set --profile 4 --rate 2
```

После выгрузки файла или штатного закрытия IINA выполняется:

```sh
/usr/local/bin/displayctl set --profile default --rate default
```

## Стандартное сопоставление

| Метаданные видео | Название профиля монитора |
| --- | --- |
| PQ | HDR Video (P3-ST 2084) |
| HLG | Apple XDR Display (P3-2000 nits) |
| BT.601, 525 строк | NTSC Video (BT.601 SMPTE-C) |
| BT.601, 625 строк | PAL & SECAM Video (BT.601 EBU) |
| BT.709 | HDTV Video (BT.709-BT.1886) |
| BT.2020 SDR | Apple XDR Display (P3-2000 nits) |
| DCI-P3 | Digital Cinema (P3-DCI) |
| Display P3 | Apple XDR Display (P3-2000 nits) |
| Adobe RGB | Photography (Adobe RGB-D65) |
| RGB-контент sRGB | Internet & Web (sRGB) |

Для HLG и SDR BT.2020 используется общий режим Apple XDR, поскольку в рассматриваемом списке нет отдельных референсных режимов для этих форматов.

## Настройка

Индекс частоты обновления задаётся в начале скрипта:

```lua
local PLAYBACK_RATE = "2"
```

Это индекс частоты `displayctl`, а не значение частоты в герцах. При необходимости замените его индексом, подходящим для вашего монитора.

## Решение проблем

Проверьте доступность утилиты и списка профилей:

```sh
/usr/local/bin/displayctl profiles
```

Названия сравниваются точно. Если у вашего монитора они отличаются, измените таблицы `PRESET_BY_TRANSFER` или `PRESET_BY_PRIMARIES` в Lua-скрипте.

Список профилей кэшируется один раз для каждого экземпляра плеера IINA. После изменения референсных режимов перезапустите IINA.

При принудительном завершении или аварии приложения восстановление невозможно, поскольку Lua не получает событие завершения.
