# Переключатель профилей displayctl для IINA

[English version](README.md)

Компактный Lua-скрипт для [IINA](https://iina.io/) и mpv на macOS. Он определяет цветовые метаданные воспроизводимого видео, находит подходящий референсный режим Apple в выводе `displayctl profiles`, переключает монитор по актуальному номеру профиля и восстанавливает системные настройки после завершения воспроизведения.

> **О проекте:** Скрипт создан OpenAI Codex по инструкциям автора проекта. Исходный релиз 1.0.0 протестирован на реальном оборудовании. Для версии 1.0.1 выполнены автоматические регрессионные проверки; их ограничения описаны ниже.

В работе скрипта используется утилита управления монитором [VitaliyYakob/displayctl](https://github.com/VitaliyYakob/displayctl), ранее опубликованная автором проекта.

## Возможности

- Получает `primaries`, `gamma` и `colormatrix` из свойства mpv `video-params`.
- Сопоставляет метаданные видео с точными названиями профилей из `displayctl`.
- Определяет номера профилей динамически, без жёстко заданных номеров.
- Кэширует разобранный список профилей на время работы экземпляра плеера IINA.
- Устанавливает выбранный индекс частоты обновления во время воспроизведения.
- Сохраняет настройки между элементами плейлиста: другой профиль включает напрямую, одинаковый не применяет повторно.
- Восстанавливает `--profile default --rate default` после фактической остановки, завершения плейлиста или штатного выхода из IINA.
- Обрабатывает аудиофайлы, отсутствие метаданных и удержание последнего кадра в режиме `keep-open`.
- Показывает в OSD IINA метаданные видео, название профиля и найденный номер.

## Требования

- macOS
- IINA с включённой поддержкой Lua-скриптов mpv
- [VitaliyYakob/displayctl](https://github.com/VitaliyYakob/displayctl), установленный по пути `/usr/local/bin/displayctl`
- Монитор, референсные режимы которого доступны через `displayctl profiles`

## Установка

1. Откройте в IINA **Настройки → Дополнительно**.
2. Включите **Use config directory** и укажите `~/.config/mpv`.
3. Если каталога для скриптов нет, создайте его:

   ```sh
   mkdir -p ~/.config/mpv/scripts
   ```

4. При обновлении сначала сохраните установленный скрипт через `cp -p`, например под именем `iina-display-profile.lua.before-1.0.1`. Скопируйте `iina-display-profile.lua` в:

   ```text
   ~/.config/mpv/scripts/iina-display-profile.lua
   ```

5. Полностью завершите IINA и запустите приложение снова.

## Принцип работы

При загрузке первого файла скрипт выполняет:

```sh
/usr/local/bin/displayctl profiles
```

Вложенные строки профилей индексируются по точному названию. Например:

```text
[1] Studio Display XDR (Основной):
    [3] HDR Video (P3-ST 2084)
    [4] HDTV Video (BT.709-BT.1886) *
```

Для видео с BT.709 и функцией передачи BT.1886 выбирается название `HDTV Video (BT.709-BT.1886)`. Скрипт находит для него номер `4` и выполняет:

```sh
/usr/local/bin/displayctl set --profile 4 --rate 2
```

Выгрузка файла не сбрасывает настройки: mpv выгружает файлы и при переходе к следующему элементу плейлиста. Скрипт наблюдает за `idle-active` и `eof-reached`. После перехода в простой или удержания последнего кадра он ждёт 0,4 секунды и повторно проверяет состояние перед восстановлением. Событие `start-file` сразу отменяет ожидающий сброс, даже если следующий файл загружается долго. Пауза, перемотка и буферизация не вызывают восстановления. При возобновлении просмотра с удержанного последнего кадра профиль видео применяется снова.

После подтверждённого завершения воспроизведения или штатного закрытия IINA выполняется:

```sh
/usr/local/bin/displayctl set --profile default --rate default
```

Для аудиофайлов, включая обложки альбомов, неизвестных цветовых метаданных и отсутствующего профиля восстанавливаются настройки по умолчанию. Профиль предыдущего видео не сохраняется. Отсутствующие метаданные проверяются повторно до 5 секунд после загрузки; последующие изменения `video-params` или дорожек запускают новую проверку. Ошибка команды монитора сбрасывает кэш активного профиля и вызывает попытку восстановления. Если восстановление не удалось, сохраняется повторная попытка при выходе.

## Стандартное сопоставление

| Метаданные видео | Название профиля монитора |
| --- | --- |
| PQ | HDR Video (P3-ST 2084) |
| HLG | Apple XDR Display (P3-2000 nits) |
| BT.601, 525 строк | NTSC Video (BT.601 SMPTE-C) |
| BT.601, 625 строк | PAL & SECAM Video (BT.601 EBU) |
| BT.709 | HDTV Video (BT.709-BT.1886) |
| BT.2020 SDR | Apple XDR Display (P3-2000 nits) |
| DCI-P3 | Digital Cinema (P3-DCI) |
| Display P3 | Apple XDR Display (P3-2000 nits) |
| Adobe RGB | Photography (Adobe RGB-D65) |
| RGB-контент sRGB | Internet & Web (sRGB) |

Для HLG и SDR BT.2020 используется общий режим Apple XDR, поскольку в рассматриваемом списке нет отдельных референсных режимов для этих форматов.

## Настройка

Индекс частоты обновления задаётся в начале скрипта:

```lua
local PLAYBACK_RATE = "2"
```

Это индекс частоты `displayctl`, а не значение частоты в герцах. При необходимости замените его индексом, подходящим для вашего монитора.

`RESTORE_DELAY` (0,4 секунды) задаёт задержку подтверждения простоя или конца воспроизведения. `METADATA_TIMEOUT` (5 секунд) ограничивает один цикл ожидания метаданных; это не ограничение времени загрузки файла. Перед настройкой сохраните резервную копию скрипта.

## Решение проблем

Проверьте доступность утилиты и списка профилей:

```sh
/usr/local/bin/displayctl profiles
```

Названия сравниваются точно. Если у вашего монитора они отличаются, измените таблицы `PRESET_BY_TRANSFER` или `PRESET_BY_PRIMARIES` в Lua-скрипте.

Список профилей кэшируется один раз для каждого экземпляра плеера IINA. После изменения референсных режимов перезапустите IINA.

При принудительном завершении или аварии приложения восстановление невозможно, поскольку Lua не получает событие завершения.

Кэш активного профиля предполагает, что другие приложения и экземпляры плеера IINA не меняют тот же монитор во время просмотра. Скрипт не координирует несколько одновременно работающих плееров.

## Проверка

Из каталога проекта выполните:

```sh
luac -p iina-display-profile.lua
lua tests/profile_switcher_test.lua
```

29 регрессионных сценариев имитируют события, свойства, таймеры mpv и ошибки displayctl без изменения монитора. Проверяются плейлист из 100 файлов, прямые переходы SDR/HDR, медленная загрузка, остановка, пауза, буферизация, повтор, удержание последнего кадра и возобновление, аудио, тайм-аут метаданных и выход. Все сценарии проходят на Lua 5.5.1 и LuaJIT 2.1 из IINA 1.4.4. Исходная версия 1.0.0 не проходит проверку переходов в плейлисте.

Воспроизведение и физическое переключение монитора для версии 1.0.1 не проверялись. Попытка загрузить установленную библиотеку IINA libmpv вне приложения завершилась ошибкой: комплектная libplacebo не предоставила `_pl_log_create_349`. IINA и установленный скрипт воспроизведения не изменялись.

После установки проверьте на мониторе плейлист с одинаковыми профилями, переход SDR/HDR, Stop, последний элемент плейлиста и штатный выход из IINA. Для отката восстановите установленный скрипт из резервной копии и перезапустите IINA; исходник также доступен в Git-теге `v1.0.0` как `iina-display-profile.lua` в корне репозитория.
